\topic{Overview.}
A multilayer perceptron classifies each survey response as Soccer, Baseball or
Basketball. Inputs are the 208 features of the proposal (12 questions encoded by
\texttt{encode\_all.py}, plus 7 missingness flags, median/mode imputation,
$\log(1+x)$ payment and standardized Q1--Q4/payment), all fitted on training rows only.
Code: \path{MLP_training/}; submission: \path{MLP_training/submission/}.

\section{Optuna tuning}
Optuna (TPE sampler, seed 311, median pruner) ran 60 trials. Each trial was scored by
grouped 5-fold cross-validation on \texttt{train.csv} only (606 rows, 202 respondents,
\texttt{GroupKFold} by respondent, seed 311), with preprocessing refitted inside every fold.
Each fold trained for 300 epochs; the epoch count was selected as the epoch with the
highest mean CV accuracy. Validation and test were not read.

The selected trial reached 90.92\% CV accuracy. That score is optimistic because it
was measured on the folds used for tuning. On the forest's 15 grouped folds
(fold seeds 311--313) the same configuration scores $89.66\pm1.17\%$, which is the
figure we compare with the other families.

\section{Training}
The network is $208 \rightarrow 128 \rightarrow 3$ with ReLU, dropout 0.5 and a softmax
output, trained with cross-entropy loss for the selected 75 epochs (no early stopping
on validation). We first trained on \texttt{train} and scored \texttt{validation} once.
Then we refitted on train plus validation (738 rows, 246 respondents) and scored the
local \texttt{test} split once.

\section{Inference on user inputs}
\texttt{pred.py} imports only the standard library, NumPy and pandas, as required.
Its function \texttt{predict\_all(filename)} reads a CSV and returns one label per row.
It rebuilds the full encoder in NumPy: multi-hot answers, TF-IDF with the stored
vocabulary and IDF weights, payment parsing, imputation, $\log(1+x)$ and scaling.
The forward pass is $\mathrm{softmax}(\mathrm{ReLU}(xW_0+b_0)W_1+b_1)$. All parameters
are in \texttt{mlp\_params.npz} (413\,KB).

The NumPy features matched the scikit-learn pipeline to within $10^{-16}$ on every
train and validation row, and predictions matched PyTorch exactly. Sixty predictions
take about 0.2\,s.

Running \texttt{python pred.py} with no arguments starts an interactive mode. It asks the
12 survey questions in the terminal, encodes the answers in the same way, and prints
one live prediction with class probabilities. For example, a response with ease 3,
indoor, school and community venues, summer, hip-hop music, ``hot dogs, peanuts, beer'', navy
blue, and ``take me out to the ball game'' was predicted as Baseball (99.1\%). This mode
is one line at the end of the file and can be commented out.
