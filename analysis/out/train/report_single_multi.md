# 单选 / 多选题：实数映射、均值方差与分类别分布

数据：`data/splits/train.csv`，共 606 行 = 202 + 202 + 202 行（3 类完全均衡：Baseball、Basketball、Soccer）。三类样本量相同，因此类均值之间可直接比较、无需加权。

> 说明：读入时使用 `keep_default_na=False`，避免真实回答 `None` / `N/A` 被误判为缺失。

## 数据切分：train / val / test

全量数据 `data/class_dataset.csv`：870 行 / 290 个 `id`。切分清单见 `data/splits/id_to_split.csv` 与 `data/splits/split_summary.json`。

**本报告只使用 train 集**（`data/splits/train.csv`，606 行）；val / test 不参与任何统计与画图。

| 集合 | 行数 | 分组数（`id`） | 占分组比例 | 各类行数 |
|---|---:|---:|---:|---|
| train | 606 | 202 | 69.7% | Baseball 202 / Basketball 202 / Soccer 202 |
| val | 132 | 44 | 15.2% | Baseball 44 / Basketball 44 / Soccer 44 |
| test | 132 | 44 | 15.2% | Baseball 44 / Basketball 44 / Soccer 44 |
| **合计** | **870** | **290** | **100%** | — |

**切分方式**：

1. 目标比例 **70% / 15% / 15%**（按分组计）。290 个分组无法被 0.15 整除，实际切出 train 202 组 / val 44 组 / test 44 组（69.7% / 15.2% / 15.2%）。
2. **按 `id` 分组切分（group split），不是按行随机切分**：每个 `id` 的 3 行必须落在同一个集合，否则同一受访者会同时出现在 train 和 test，指标虚高。
3. **不是分层抽样（stratified sampling）**，但因为每个 `id` 恰好包含 Soccer / Baseball / Basketball 各一行，切分后**每个集合天然三类均衡**（1:1:1），效果等价于完美分层。
4. 具体排列由 `sha256("<seed>:<id>")` 排序决定（seed=311），**不依赖任何随机数发生器状态**，因此与 numpy 版本、平台、CSV 行序无关，重复运行得到的切分文件逐字节一致。
5. 复现：`python analysis/make_splits.py --seed 311 --test-size 0.15 --val-size 0.15`，或用 `--from-manifest data/splits/id_to_split.csv` 直接复用清单。

> **统计注意事项**：本数据只含 202 个 `id`、共 606 行，平均每个 `id` 3.0 行（同一受访者回答了多项运动），行与行并不独立。下表 χ² / ANOVA 的 p 值是按「行独立」计算的，因此**偏乐观（过于显著）**；效应量（Cramér's V、η²）是描述性的、不受此影响，判断特征强弱请以效应量为准，若要严格推断需用聚类稳健方法（如 GEE / 混合效应模型）。

## 一、单选题（5 点 Likert → 序数 1–5）

映射：`Strongly disagree=1, Disagree=2, Neutral=3, Agree=4, Strongly agree=5`。把李克特标签当等距序数处理，均值可解释为「态度分数」，方差反映意见分歧度。

## 二、多选题（复选框 → 每个选项一个 0/1 变量）

映射：某选项被勾选 → 1，未勾选 → 0。因此**均值 = 勾选率（比例）**，方差 = p(1−p)·n/(n−1)（伯努利方差，p≈0.5 时最大）；另加「勾选个数」这一实数特征。
